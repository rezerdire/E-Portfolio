# E-Portfolio

Personal portfolio built with React, Vite, and Tailwind CSS.

## Skills section

The skills section uses a categorized tab layout:

- **Frontend** is displayed by default.
- **Backend**, **Database**, **Tools**, and **Other** are available through the category tabs.
- Each category uses compact skill rows with qualitative levels and visual proficiency bars.
- Tabs remain horizontally scrollable on small screens, while skill rows become a single-column layout.

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
